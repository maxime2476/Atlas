# Météo-France — SIM2 quotidienne (SAFRAN-ISBA), 2009-2025

- Source : https://www.data.gouv.fr/datasets/donnees-changement-climatique-sim-quotidienne (Licence Ouverte 2.0)
- Fichiers : `QUOT_SIM2_<année>.csv.gz` (≈ 137 Mo/an), grille `coordonnees_grille_safran_lambert-2-etendu.csv`, deux notices PDF.
- 2009 est nécessaire pour les semis de l'automne 2009 (récolte 2010).
- Les quatre dernières années sont révisées deux fois par mois par Météo-France : comparer les SHA-256 au manifeste avant tout recalcul.
